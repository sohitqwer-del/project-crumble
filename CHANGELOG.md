# Changelog

## 0.1.0a1

Initial standalone Project Crumble alpha.

- Local garment ingestion with multiple views, source rights and snapshots.
- Versioned demo and optional FashionSigLIP image/text embedding providers.
- Resumable jobs, exact retrieval and optional HNSW indexes.
- Responsive photo search, manual cropping, garment details and part corrections.
- Design comparison, candidate review queue, history API and review export.
- Operation-based SMV change ranges with traceable time libraries.
- Authentication, upload limits, stale-write checks and release tests.
- Synthetic demo, installation guidance, container definition and public CI.

Known limits: no enterprise SSO, distributed storage/workers, validated total
garment SMV, automatic pattern-piece reconstruction or verified 98% retrieval.
Private adapters and retailer data are not included.
