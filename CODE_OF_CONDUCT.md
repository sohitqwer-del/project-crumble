# Community conduct

Treat contributors and users with respect. Discuss the code and evidence rather
than attacking the person. Welcome questions from people with different language,
technical and garment-production backgrounds.

Harassment, threats, discriminatory remarks, unwanted sexual attention and
sharing another person's private information are not acceptable.

Maintainers may edit or remove harmful content, pause a discussion, or restrict
participation. Apply these actions consistently and explain decisions where
doing so will not expose private information.

For a concern involving private information, ask a maintainer for a private
contact method without posting the information publicly. Maintainers should
handle reports discreetly and avoid conflicts of interest.
