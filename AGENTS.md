# Project Crumble

This is the standalone open-source Project Crumble repository, connected to
https://github.com/sohitqwer-del/project-crumble.

Develop, run and test the application locally. On this Windows workstation the
checkout is E:\project-crumble. Use its .venv; keep runtime workspaces, model
caches, credentials and production data out of Git.

The remote server may be used for authorised training, GPU work and evaluation
against private data. It is not required to run the website or application.
Never read E:\the db. Treat the private catalogue as read-only. Do not publish
retailer imagery, private reviews, factory standards or trained weights without
redistribution rights. Do not restart shared GPU/Ollama services.

Keep image/model/index identity and source snapshots consistent. Unknown parts
are not absent parts. Inferred claims are proposals. SMV suggestions need
explicit operation times and factory review. Do not invent accuracy claims.

The website lives in website/dist. Its public demo uses original project
illustrations and explicitly illustrative operation times. Keep its Crumble
brand consistent with the reviewer application. Real retailer names describe
source records only; do not imply sponsorship or customer adoption.

Preserve existing user work. Back up files before editing. Run relevant tests
and browser checks, then publish authorised completed changes. Production
deployment identity is declared in .openai/hosting.json.
